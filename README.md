# 作ったもの

個人で作ったアプリ・道具・構想の一覧ページです。

**見る：** https://nndahedeyo.github.io/

## 足し方

`apps.js` の並びに `{ ... }` を1つ足すだけです。並び順は `date` の新しい順に自動で並び、日本語と英語は端末の言語で切り替わります。

| 項目 | 中身 |
|---|---|
| `name` / `desc` | 名前と説明（`ja` と `en`） |
| `status` | `live`（公開中）・`trial`（試験版）・`building`（作っているところ）・`idea`（構想） |
| `kind` | `app`（アプリ）・`tool`（道具）・`site`（サイト）・`idea`（構想） |
| `url` | 開くページ（なければ空） |
| `repo` | GitHub のページ（なければ空） |
| `date` | 始めた日 |
| `mark` / `color` | 札の文字（1〜2文字）と色 |

---

## English

A list of apps, tools and concepts made by one indie developer. To add one, append an entry to `apps.js`; entries sort by `date`, newest first. The page follows the device language (Japanese or English).
